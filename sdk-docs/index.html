FotoOwl Media SDK

A framework-agnostic media SDK ecosystem for searching, retrieving and interacting with image and video content powered by the Pexels API.

Overview

FotoOwl separates data access, framework integration and UI behavior into independent packages. This makes the SDK reusable across React, React Native and other environments.

@fotowl/media-core

Framework-agnostic TypeScript SDK for Pexels API communication, caching, pagination and events.

@fotowl/media-react

React provider and hooks for consuming the media core through React applications.

@fotowl/media-native

React Native provider for using the same media core contract in native applications.

Architecture

Application │ ├── media-ui-react │ └── media-react │ ▼ media-core │ ▼ Pexels API

The core package contains the data and API logic. Framework-specific packages provide integration without duplicating business logic.

Installation

Install the core SDK:

npm install @fotowl/media-core

For React applications:

npm install @fotowl/media-react

For React Native applications:

npm install @fotowl/media-native

Media Core

@fotowl/media-core is the foundation of the FotoOwl SDK. It does not depend on React, React Native or browser-specific UI components.

Create a client

import { createMediaClient } from "@fotowl/media-core";

const media = createMediaClient({
  apiKey: "YOUR_PEXELS_API_KEY"
});

Photo API

searchPhotos(query, page?, perPage?)

Search Pexels for photos. 

const result = await media.searchPhotos(
  "mountains",
  1,
  20
);

console.log(result.photos);
curatedPhotos(page?, perPage?)

Retrieve curated photo results.

getPhotoById(id)

Retrieve a single photo by its Pexels ID. 

const photo = await media.getPhotoById(123456);

Video API

searchVideos(query, page?, perPage?)

Search Pexels for videos. 

const result = await media.searchVideos(
  "nature",
  1,
  20
);

console.log(result.videos);
curatedVideos(page?, perPage?)

Retrieve curated video results.

getVideoById(id)

Retrieve a single video by its Pexels ID. 

const video = await media.getVideoById(123456);

Events

The SDK provides lightweight event tracking for media interactions.

Track a view

media.trackView(mediaId);

Track a download

media.trackDownload(mediaId);

Events contain the event type, media ID and timestamp. The SDK also provides a default console listener.

Caching & Request Deduplication

The core SDK includes a lightweight in-memory cache with a default TTL of five minutes.

  • Repeated requests can be served from cache.
  • Expired cache entries are removed automatically.
  • Identical requests already in progress are deduplicated.
  • The cache can be cleared when required.
media.clearCache();

React SDK

@fotowl/media-react provides React integration without moving API logic into UI components.

Provider

import {
  MediaProvider
} from "@fotowl/media-react";

function App() {
  return (
    <MediaProvider apiKey={API_KEY}>
      <MyApplication />
    </MediaProvider>
  );
}

Photo search hook

import {
  useMediaSearch
} from "@fotowl/media-react";

function Gallery() {
  const {
    data,
    loading,
    error,
    search,
    loadMore,
    hasMore
  } = useMediaSearch();

  // Use data in your UI
}

Video search hook

const {
  data,
  loading,
  error,
  search
} = useMediaVideoSearch();

React Native SDK

@fotowl/media-native provides the same core media client through a React Native provider. 

import {
  MediaNativeProvider,
  useMediaNative
} from "@fotowl/media-native";

function App() {
  return (
    <MediaNativeProvider apiKey={API_KEY}>
      <MobileApp />
    </MediaNativeProvider>
  );
}
