FotoOwl Components

Headless media UI components for building flexible image and video experiences across React and React Native.

Overview

The FotoOwl UI packages provide reusable interaction behavior while leaving visual presentation to the consuming application.

Grid

Media collection with infinite scrolling and load-more support.

Lightbox

Full-screen media viewer with keyboard and navigation support.

Reel

Vertically scrolling, snap-based media experience with active item detection.

Architecture

Application │ ├── media-ui-react │ └── media-ui-native │ ▼ Headless UI behavior

UI components do not communicate directly with the Pexels API or the media SDK. Data and actions are supplied through component props.

The consuming application owns media rendering, styling, API integration and business logic.

Grid

Grid<T>

A generic media collection component that supports rendering arbitrary data and triggering additional data loading when the user reaches the end of the collection.

Usage

import { Grid } from "@fotowl/media-ui-react";

<Grid
  items={photos}
  hasMore={hasMore}
  loading={loading}
  onLoadMore={loadMore}
  renderItem={(photo) => (
    <img
      src={photo.src.medium}
      alt={photo.alt}
    />
  )}
/>

Props

Prop Type Description
items T[] Items to display.
renderItem (item, index) => ReactNode Controls how each item is rendered.
onLoadMore () => void Called when more data should be loaded.
hasMore boolean Indicates whether additional data exists.
loading boolean Prevents repeated loading while a request is active.

Lightbox

Lightbox<T>

A headless media viewer that provides close and previous/next navigation behavior.

Usage

import { Lightbox } from "@fotowl/media-ui-react";

<Lightbox
  isOpen={isOpen}
  item={selectedPhoto}
  onClose={handleClose}
  onNext={handleNext}
  onPrevious={handlePrevious}
  renderItem={(photo) => (
    <img
      src={photo.src.large}
      alt={photo.alt}
    />
  )}
/>

Props

Prop Type Description
isOpen boolean Controls whether the lightbox is visible.
item T | null Currently selected media item.
onClose () => void Closes the lightbox.
onNext () => void Moves to the next item.
onPrevious () => void Moves to the previous item.
renderItem (item) => ReactNode Controls media presentation.

Keyboard Navigation

  • Escape closes the lightbox.
  • ArrowRight moves to the next item.
  • ArrowLeft moves to the previous item.

Reel

Reel<T>

A vertical media experience using scroll snapping and visibility detection to identify the active item.

Usage

import { Reel } from "@fotowl/media-ui-react";

<Reel
  items={videos}
  onActiveChange={(video, index) => {
    console.log("Active:", video.id);
  }}
  renderItem={(video, index, isActive) => (
    <video
      src={video.videoFiles[0].link}
      autoPlay={isActive}
      muted
      loop
      playsInline
    />
  )}
/>

Props

Prop Type Description
items T[] Items displayed in the reel.
renderItem (item, index, isActive) => ReactNode Controls the media presentation.
onActiveChange (item, index) => void Called when the active item changes.

Active Media

The isActive value can be used by the consuming application to control behaviors such as video autoplay and playback.

React Package

The React components are available through: 

import {
  Grid,
  Lightbox,
  Reel
} from "@fotowl/media-ui-react";

These components are intentionally independent from @fotowl/media-core and @fotowl/media-react.

React Native Package

React Native equivalents are available through: 

import {
  Grid,
  Lightbox,
  Reel
} from "@fotowl/media-ui-native";

The native package uses platform-specific primitives such as FlatList and Modal while maintaining the same headless component philosophy.

Native Grid

<Grid
  items={photos}
  hasMore={hasMore}
  loading={loading}
  onLoadMore={loadMore}
  renderItem={(photo) => (
    <Image
      source={{ uri: photo.src.medium }}
    />
  )}
/>

Native Reel

<Reel
  items={videos}
  onActiveChange={handleActiveChange}
  renderItem={(video, index, isActive) => (
    // React Native media UI
  )}
/>

Accessibility

The components provide interaction behavior while the consuming application remains responsible for accessible media content and labels.

  • Use meaningful alt text for images.
  • Provide accessible labels for custom controls.
  • Use semantic buttons for interactive actions.
  • Ensure sufficient color contrast in application styling.
  • Provide keyboard-accessible controls on web.
Headless components intentionally avoid imposing a visual design system so applications can implement their own accessibility and branding requirements.

Styling

The UI packages do not impose a CSS framework or visual design system.

Applications control styling through their own CSS, Tailwind classes, CSS modules or other styling solutions. 

<Grid
  items={photos}
  renderItem={(photo) => (
    <article className="photo-card">
      <img
        src={photo.src.large}
        alt={photo.alt}
      />
    </article>
  )}
/>
